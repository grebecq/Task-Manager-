# Task Management System

Сервис для постановки и ведения задач: создать задачу, назначить исполнителя, взять в работу, закрыть. Есть поиск по статусу, приоритету и исполнителю.

**Как устроено:** Spring Boot, Spring Data JPA и PostgreSQL, схема БД через Flyway, вход по JWT (Spring Security). Веб-интерфейс — статические страницы, которые раздаёт само приложение.

## Запуск

Нужен только Docker:

```bash
docker-compose up -d
```

Откройте http://localhost:8080, там будет страница входа. Остановить: `docker-compose down`.
